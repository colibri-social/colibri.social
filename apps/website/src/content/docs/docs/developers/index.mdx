Colibri (pronounced **/ˈkoʊ lɪ bri/**) is a chat app built on the AT Protocol.
Your messages live in your own repository and travel with your identity.

A Colibri Space is built on
[ATproto spaces](/docs/developers/architecture/spaces), a part of the protocol that
lets a group of repositories agree on who may read them. Most of these docs
build on it.

:::note[If you use Colibri and don't develop for it]
Start with the [user documentation](/docs).
:::
