A Space consists of an account that holds it, and a Colibri server that delivers it to your app.

For members, none of this needs any setup! This page is relevant to you if you own a Space, if you want to use a different server, or if a Space you joined doesn't show up.

## The account behind a Space

Every Space has an account of its own. It holds the channels, the roles and the list of members. When you create a Space, **Who hosts this Space** sets who runs that account:

- **Colibri hosts it**: Colibri runs the account for your Space. There is nothing to set up.
- **Use an account I own**: the Space lives on an account you own, with a provider you chose. You sign in as that account while you create the Space. The provider has to support Spaces, and Colibri checks that for you. Use an account made only for this Space.

Both kinds of Space work the same way for members.

### Check how your Space is hosted

The owner of a Space sees this under **Manage Space** > **Hosting**. The page reads **Hosted by Colibri** or **Hosted on your own account**. Only the owner can open it.

## The server behind a Space

A Colibri server delivers messages to your app, sends notifications and connects voice calls. Colibri is open source, so anyone can run such a server!

Each Space belongs to the server it was created on. Your app connects to a single server too, which does not need to be the same one that holds your Space. The apps from colibri.social connect to the server that Colibri runs, unless you pick another one.

Colibri servers work together. From your app, you can join and use a Space that belongs to another server:

- Messages, reactions, threads and voice calls work the same way as in a Space on your own server.
- Members on every server see your online status and when you're typing.
- Mentions and replies reach you as notifications through your own server.
- An invite link works no matter which server the Space belongs to. Open it and join as usual.

You use the same account and the same handle on every Colibri server.

## Change your server

<Steps>

1. Open **Settings** > **Advanced**. The **Server** section shows the server your app connects to.

2. Select **Change server** and enter the address of the server, for example `colibri.example.com`.

3. Select **Check server**. Colibri checks the address and lists what that server does.

4. Select **Switch and sign out**.

5. Sign in again with the same account.

</Steps>

To return to the server your app came with, select **Go back to** followed by its address.

Before you switch, check the list Colibri shows. A server that shows **Only shows Spaces that run on this server** doesn't work together with other servers. While you use it, Spaces you joined on other servers don't appear.

## A Space can't be reached

The server of the Space isn't responding. Colibri shows that the Space can't be reached right now and names the server it belongs to.

Nothing you've sent is lost. The Space opens again on its own once its server is back. To check sooner, select **Try again**.

## A Space you joined doesn't appear

Check these in order:

- **Your server doesn't work together with other servers.** It only lists Spaces that belong to it. Ask the people who run your server, or switch to one that works with other servers.
- **You left the Space, or were removed from it.** Ask someone in the Space for a new invite link.

## You can read a Space and can't moderate it

That depends on your roles in the Space, and has nothing to do with hosting. Ask the owner to check your roles, and read [Roles and Permissions](/docs/users/spaces/roles-and-permissions).
